# התרופות שלי — pillApp

אפליקציית ווב (PWA) לניהול ותזכורות לקיחת תרופות. אישית, בעברית, מותאמת לעיניים מבוגרות.

**גרסה נוכחית:** `2026-09-02 21:05 v3 dual-photo-id` — מוצגת בתחתית כל מסך באפליקציה.

## ארכיטקטורה

**אין שרת. אין בסיס נתונים. אין תלות בבנייה.** קבצים סטטיים בלבד + ES modules.

```
index.html            מעטפת: מסכים, שכבות, טאבים
css/app.css           מערכת עיצוב אחת (טוקנים, בהיר/כהה, RTL)
js/store.js           מודל הנתונים + localStorage + BUILD
js/schedule.js        חישוב מנות, ימים שקטים, מלאי, היענות
js/text.js            ניסוח עברי אישי לפי שם ומגדר
js/notify.js          מנוע התזכורות: נדנוד, נודניק, קול, יום שקט
js/sensors.js         חיישן תנועה (השכמה) + מיקום (יציאה מהבית)
js/tools.js           פנס + זכוכית מגדלת (מצלמה משותפת)
js/gemini.js          זיהוי מצילום + כרטיס מידע מקורקע בחיפוש
js/dom.js             עזרי DOM, טוסטים, גיליון תחתון, דיאלוגים
js/ui.js              מסכים, התזכורת הגדולה, מסך שבת
js/editors.js         עורך תרופה, כרטיס מידע, עורך פרוצדורה
js/app.js             אתחול וחיווט
sw.js                 עבודה בלי רשת + לחיצה על התראה
```

### למה לא מאגר משרד הבריאות ישירות
נבדק בפועל: `israeldrugs.health.gov.il` מוגן ב-WAF שמחזיר דף שגיאה לכל בקשה שאינה דפדפן אמיתי,
ו-`data.gov.il` לא מפרסם את מאגר התרופות. פרוקסי שמחקה דפדפן היה נשבר כל כמה שבועות.
במקום זה, כרטיס המידע מיוצר ב-Gemini עם **חיפוש גוגל מקורקע** — כולל קישורים למקורות שעליהם הוא התבסס
(ביניהם העלון לצרכן ומאגר משרד הבריאות עצמו). `generativelanguage.googleapis.com` מאפשר CORS מהדפדפן,
ולכן אין צורך בשרת כלל.

### זיהוי מתמונה — שני מסלולים, בכוונה

הצינור דו-שלבי: **קריאה ויזואלית** (`responseSchema`, בלי חיפוש — כדי שלא ימציא מה שלא רואים)
ואז **חיפוש מקורקע** שמשלים את כל השאר. מה שנעשה עם התוצאה תלוי במקור:

- **אריזה** — נמדד כאמין. מילוי אוטומטי אגרסיבי: שם, חומר פעיל, חוזק, צורה, כמות, תנאי לקיחה,
  שעות, גודל אריזה, מלאי התחלתי, וכרטיס המידע המלא. בבדיקה: 10 שדות בלחיצה אחת.
- **כדור בלבד** — נמדד כ**לא אמין** ולכן **אינו ממלא כלום מעצמו**. בבדיקה עם חריטה `TEVA 3109`
  המודל החזיר `identified:false`, אפס מקורות, והזהיר שייתכן שזו תרופה אחרת לגמרי. מוצג פאנל
  כתום עם ההשערה והסתירה; מילוי רק באישור מפורש, ורק אם אין אזהרת אי-התאמה.
- **שניהם יחד** — האריזה קובעת, והכדור נבדק מולה. אי-התאמה מוצגת כאזהרה אדומה, כי כדור שגוי
  באריזה הוא תרחיש קיים.

### מפתח Gemini
נשמר **רק ב-localStorage של המכשיר**. אינו בקוד, אינו ב-repo, ואינו נשלח לשום מקום מלבד Google.
משיגים חינם ב-<https://aistudio.google.com/apikey>, ומדביקים פעם אחת ב**הגדרות ← זיהוי מצילום ומידע על תרופות**.
בלי מפתח האפליקציה עובדת במלואה — פרט לזיהוי-מצילום ולכרטיס המידע.

## הרצה

**מקומית (מחשב):** לחיצה כפולה על `התרופות שלי.lnk`, או `start.bat`. נפתח ב-<http://localhost:8899>.

**בטלפון:** צריך HTTPS — Service Worker, התראות, מצלמה ומיקום אינם עובדים על `http://` בכתובת LAN.
מארחים את התיקייה בכל אחסון סטטי (GitHub Pages, Netlify, Cloudflare Pages) ומתקינים דרך
תפריט הדפדפן ← "הוספה למסך הבית".

## מגבלה שחשוב להכיר: התראות כשהאפליקציה סגורה

לדפדפנים אין תזמון התראות אמין כשהאפליקציה **סגורה לגמרי**
(`Notification Triggers` מעולם לא נכנס לשימוש רחב, ו-`Periodic Background Sync` לא מובטח).
מה שכן עובד:

- **פתוחה או ברקע** (הלשונית/ה-PWA חיה) — התזכורות מדויקות, כולל נדנוד ונודניק.
- **נסגרה ונפתחה מחדש** — האפליקציה עושה מיד "השלמת פערים" ומציגה כל מה שהוחמץ ולא סומן.
- **מסך שבת** מחזיק את המסך דלוק (Wake Lock).

אם יידרש נדנוד מובטח גם כשהטלפון נעול והאפליקציה סגורה — זה מחייב שרת Push קטן (Web Push + VAPID).
זו הרחבה אפשרית, לא נבנתה כאן.
